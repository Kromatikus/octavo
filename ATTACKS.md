# Octavo attack history

Octavo has been through twenty rounds of scrutiny so far: ten in-house attacks on the round function while it was designed (rounds 1–10), one independent review (round 11), eight in-house attacks on the outer layer (rounds 12–16 and 18–20) and one in-house constant-time and timing review (round 17). Each round looked for weaknesses, and the most serious finding was usually fixed before the next round. Only the latest full round-function report is kept in this repo: [`attacks_octavo_beat6/`](attacks_octavo_beat6/REPORT.md). The older round-function folders are in this repo's git history (first commit); the outer-layer reports (rounds 12–20) are summarized below and are not in this repo.

None of these rounds broke the full 16-round cipher or its outer construction. That is a negative experimental result, not a proof of security, and only round 11 was independent (and it covered the round function, not the later outer layer). The newest piece, rehearsal streaming (format version 8, not yet frozen), has had two in-house attacks (rounds 19 and 20: no cryptographic break; file-helper, worker and API findings). The rehearsal-fix revision applied round 19's fixes and the live rehearsal-polish revision applies round 20's, which have **not been attacked again**. **Octavo is homemade. For real secrets use AES-GCM-SIV, age, or libsodium.**
