=== N2 key schedule ===
[linearity] affine test M(a)^M(b)^M(c)^M(a^b^c): mean nonzero bits 4356/8704 (N1: exactly 0 = perfectly linear; N2 should be ~half)
[linearity] affine test in the nonce: mean nonzero bits 4361/8704
[N1-style inversion] affine model vs true material for a random seed: 4366/8704 bits wrong (affine model FAILS -> no linear seed recovery)
[seed recovery] round keys are SHA-256("SN2/K"||ctr||seed||nonce) blocks. Recovering the seed from them requires inverting SHA-256 on a 128-byte secret suffix: no known shortcut. NOT attempted (not a Python-scriptable break).
[impl] domain separation: K-stream and M-stream share 0 of 2048 bytes in order: 9 equal positions (expect ~8 by chance)
[impl] mac_key == SHA256('SN2/M'||ctr0||seed||nonce)[:32]: True
[impl] mac_key present verbatim in schedule material (seed copied into stream?): False
[impl] any 8-byte run of the seed appears verbatim in 2048 bytes of K-stream: 0 (expect 0)
[impl] seed actually used (material(seed) != material(0)): True
[impl] nonce actually used (material(nonce) != material(other nonce)): True
[impl] SHA-256 counter advances (all 64 squeezed blocks distinct): True
[impl] int seed (N1 style) and bytes seed give identical material: True
[avalanche] 1-bit nonce flip: schedule-bit change fraction mean 0.4997 (min 0.487, max 0.513)
[avalanche] 1-bit seed flip:  schedule-bit change fraction mean 0.4991 (min 0.486, max 0.515)
[avalanche] related nonces: unlike N1, the material difference is NOT predictable without the seed (it is a SHA-256 output).
